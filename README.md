# tasks-api-spring

> Modelar tarefas com responsáveis distintos, garantindo integridade referencial e evolução de schema.

## Problema

Modelar tarefas com responsáveis distintos, garantindo integridade referencial e evolução de schema.

## Solução

API REST Spring Boot 3 com JPA, relacionamento Task↔User, migrações versionadas com Flyway e MySQL provisionado via Docker Compose.

## Stack

- Java
- Spring Boot
- JPA
- MySQL
- Flyway
- Docker
